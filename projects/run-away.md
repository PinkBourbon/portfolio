# Run Away

![Run Away 게임 화면](../images/run-away.png)

| 항목 | 내용 |
| --- | --- |
| 기술 | C, WinAPI |

팀 개발 과정에서 구조와 성능 문제를 다루고, 페어 프로그래밍과 조언으로 동료의 구현을 도왔습니다. BMP의 알파 데이터와 비트맵의 피벗 위치 데이터를 생성하는 도구도 제작했습니다.

## 문제 해결: 알파 블렌딩 성능

알파 블렌딩 처리에서 성능 병목을 발견해, 반복문 안의 조건 분기를 밖으로 옮기고 함수 호출에 강제 인라인을 적용했습니다. 당시 기록의 프레임 속도 변화는 다음과 같습니다.

| 단계 | 당시 기록 |
| --- | --- |
| 변경 전 | 약 20 FPS |
| 조건 분기를 반복문 밖으로 이동 | 약 40 FPS |
| 강제 인라인 적용 | 약 60 FPS |

이 수치는 과거 Notion 기록에 남은 대략적인 값이며, 하드웨어·장면·재현용 측정 조건은 기록되어 있지 않습니다.

## 문제 해결: 순회 중 상태 변경

`OnEnable`, `Update`, `OnDisable` 콜백을 처리하던 중 객체 상태 변경이 순회 중인 목록을 수정해, 순회가 무효화되거나 잘못된 콜백이 실행되는 문제가 있었습니다.

상태 변경 요청을 즉시 적용하는 대신 **요청을 모아두고 안전한 시점에 일괄 반영**하도록 바꿨습니다. 콜백을 실행하는 과정과 목록을 수정하는 시점을 분리해 이 문제를 해결했습니다.
